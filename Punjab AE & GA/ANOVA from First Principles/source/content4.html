12Formula sheet

Total SS & variance
$\SST=\sum_i (y_i-\bar y)^2,\quad s^2=\SST/(n-1)$
One-way identity
$\SST=\SSB+\SSW$
Between SS
$\SSB=\sum_i n_i(\bar y_i-\bar y)^2,\ \ df=k-1$
Within SS
$\SSW=\sum_i\sum_j(y_{ij}-\bar y_i)^2,\ \ df=n-k$
F statistic
$F=\dfrac{\MSB}{\MSW}\sim F_{k-1,\,n-k}$ under $H_0$
Expected mean squares
$E[\MSW]=\sigma^2,\ E[\MSB]=\sigma^2+\frac{\sum n_i(\mu_i-\bar\mu)^2}{k-1}$
Effect sizes
$\eta^2=\dfrac{\SSB}{\SST},\ \ \omega^2=\dfrac{\SSB-(k-1)\MSW}{\SST+\MSW}$
Regression
$\SST=\text{SSR}+\text{SSE},\ \ R^2=\text{SSR}/\SST$
$\text{VIF}_j=1/(1-R_j^2)$
Random intercept & ICC
$\sigma^2=\sigma_b^2+\sigma_w^2,\ \ \rho=\sigma_b^2/\sigma^2$
ICC from ANOVA (equal m)
$\hat\rho=\dfrac{\MSB-\MSW}{\MSB+(m-1)\MSW}$
Design effect
$\text{DEFF}=1+(m-1)\rho$
$\text{DEFT}=\sqrt{\text{DEFF}},\ \ n_{\text{eff}}=n/\text{DEFF}$
Unequal clusters & weights (Kish)
clusters: $1+\{(1+CV_m^2)\bar m-1\}\rho$
weights: $1+CV_w^2$
Margin of error for a proportion
$\text{MOE}=1.96\sqrt{\text{DEFF}\cdot p(1-p)/n}$
Optimal interviews per cluster
$m_{\text{opt}}=\sqrt{\dfrac{c_1}{c_2}\cdot\dfrac{1-\rho}{\rho}}$

13Do it in R (and Python)

Everything in this chapter can be reproduced with a few lines of R. The full, tested script ANOVA_companion.R is saved next to this PDF; the key steps are below, with the output they produce.

13.1One-way ANOVA from first principles, then in one line

[[R fert <- data.frame( type = factor(rep(c("A", "B", "C"), each = 5)), yield = c(18,20,19,21,22, 23,25,24,26,25, 20,21,22,19,20)) grand <- mean(fert$yield) gmeans <- ave(fert$yield, fert$type) # each row's own group mean SSB <- sum((gmeans - grand)^2) # signal SSW <- sum((fert$yield - gmeans)^2) # noise F <- (SSB / 2) / (SSW / 12) # 19.1 fit <- aov(yield ~ type, data = fert) # the same thing in one line summary(fit) R]] [[OUT Df Sum Sq Mean Sq F value Pr(>F) type 2 64.93 32.47 19.1 0.000187 *** Residuals 12 20.40 1.70 OUT]]

[[R tab <- summary(aov(score ~ psu, data = svy))[[1]] MSB <- tab$`Mean Sq`[1]; MSW <- tab$`Mean Sq`[2]; m <- 5 icc <- (MSB - MSW) / (MSB + (m - 1) * MSW) # 0.978 1 + (m - 1) * icc # DEFF = 4.91 library(lme4) # same ICC from a mixed model vc <- as.data.frame(VarCorr(lmer(score ~ 1 + (1 | psu), data = svy)))$vcov vc[1] / sum(vc) library(survey) # design-based SE and DEFF des <- svydesign(ids = ~booth, weights = ~wt, data = pun) svymean(~vote_A, des, deff = "replace") R]] [[OUT mean SE DEff vote_A 0.365417 0.013005 1.7498 OUT]]

15Answer key and solution hints

  1. Variance is the average squared distance from the mean (with a df adjustment in a sample). Squaring avoids cancellation and emphasises larger deviations.
  2. Mean = 6; SST = (4 − 6)² + 0² + (8 − 6)² = 8; s² = 8/2 = 4.
  3. Total variance uses deviations from the grand mean. Within variance uses deviations from each group's own mean, and estimates residual scatter after group membership is fitted.
  4. All population group means are equal: μ1 = μ2 = … = μk.
  5. Under H0 both mean squares estimate the same σ², so their ratio fluctuates around 1.
  6. Means: A = 11, B = 15, grand mean = 13.
  7. A: 1 + 1 + 0 = 2; B: 0 + 1 + 1 = 2; SSW = 4.
  8. SSB = 3(11 − 13)² + 3(15 − 13)² = 24. SST = 28 = 24 + 4 ✓.
  9. dfB = 1, dfW = 4; MSB = 24; MSW = 1; F = 24.
  10. The omnibus test evaluates the joint null. Finding which pairs differ needs contrasts or post-hoc comparisons with multiplicity control (e.g. Tukey).
  11. n = 32; dfB = 3; dfW = 28; dfT = 31.
  12. SSB = 150; η² = 150/240 = 0.625: in this sample, 62.5% of SST is associated with treatment.
  13. F = 6: the between-group variation per df is six times the error mean square, far more than noise alone would typically produce.
  14. Omitted covariates, nonlinear relationships, interactions, time trends, measurement error, latent subgroups, or dependence (clustering).
  15. Randomisation protects against systematic confounding of treatment labels; replication shows the scatter among comparably treated units.
  16. Whether the predictors, jointly, reduce the unexplained SS relative to an intercept-only model; equivalently, H0: both slopes are zero.
  17. SSR = 375; R² = 0.75; 25% of SST remains as residual in-sample.
  18. Main effect: the average effect of irrigation across all varieties. Interaction: irrigation raises yield a lot for V2 but hardly at all for V3 (Fig. 10).
  19. With a strong interaction, a main effect averages effects that differ greatly or even reverse across levels of the other factor.
  20. When group variances are materially unequal, especially with unequal group sizes. It is a reasonable default.
  21. Total variance = 45; ICC = 9/45 = 0.20.
  22. DEFF = 1 + 5(0.20) = 2.0; neff = 600/2 = 300.
  23. A: DEFF = 1 + 5(0.08) = 1.40, neff ≈ 429. B: DEFF = 1 + 19(0.08) = 2.52, neff ≈ 238. More clusters with fewer people each is far more efficient.
  24. σ²w = 10; σ²b = (18 − 10)/4 = 2; ICC = 2/12 = 0.167 (check: 8/(18 + 3·10) = 8/48); DEFF = 1 + 3(0.167) = 1.50.
  25. DEFF ≈ 1 + (1.36 × 10 − 1)(0.05) = 1 + 12.6 × 0.05 = 1.63. A design-based estimator uses the actual cluster sizes, weights, strata, finite-population corrections and the specific statistic.
  26. F divides the between-group signal by within-group noise. The means (signal) are identical, but the right panel's noise is three times larger, so MSW is about 9× larger and F shrinks about 9-fold.
  27. A non-significant F is not proof of equality: with n = 5 per brand the study can only rule out differences larger than about ±[[2.179*(2*O['batt']['msw']/5)**0.5|.1f]] hours. Better: "No evidence of a difference; differences up to ~[[2.179*(2*O['batt']['msw']/5)**0.5|.1f]] h cannot be excluded."
  28. Variances: Fast [[O['courier']['vars'][0]|.1f]], Budget [[O['courier']['vars'][1]|.1f]], Local [[O['courier']['vars'][2]|.1f]]. Classical ANOVA pools them into MSW = [[O['courier']['msw']|.1f]], dominated by Budget, which drowns the tight Fast-vs-Local gap. [[call('key','Closing perspective','bulb')]]

The most durable way to understand ANOVA is not as a special test for three or more means, but as an accounting system for variation. Total variation is split into components linked to specified structure plus a residual. Regression changes the form of the predictors but keeps the same decomposition. Multilevel models add explicit variance components. The survey design effect then follows naturally: a large between-cluster component creates intraclass correlation, which reduces the independent information each extra respondent in a PSU adds.

Once this viewpoint is clear, ANOVA, regression, ICC, random effects, cluster sampling, DEFF and effective sample size become parts of one coherent framework rather than a set of disconnected formulas.
